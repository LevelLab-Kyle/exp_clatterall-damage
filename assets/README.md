# Assets

Sound effects picked from the Level Lab asset library, embedded as base64 in `sounds.js` so `index.html` works straight from disk. (The gadgets themselves are drawn with primitive shapes; see `src/gadgets.js`.)

To swap or add one, drop the raw `.glb` / `.mp3` files in a folder and run `python3 assets/pack.py <folder>`; the file name becomes the key.
